# VERTIKAL — визуальный концепт интернет-магазина

Концепт главной страницы магазина VERTIKAL в Павлово: одноразовая посуда, бытовая химия, упаковочные материалы и расходники для кафе, ресторанов, столовых и компаний.

## Структура

```text
Мичурина/
├── index.html       # главная страница магазина
├── product.html     # пример карточки товара
├── account.html     # пример личного кабинета оптового клиента
├── css/
│   └── styles.css   # общая дизайн-система и адаптивные стили
├── js/
│   └── app.js       # демонстрация поиска и добавления в корзину
└── images/
    └── README.md    # правила для локальных изображений
```

## Запуск

Сборщик и backend не требуются. Откройте `index.html` в браузере. Переходы на карточку товара и личный кабинет уже добавлены в интерфейс.

Для локального сервера можно использовать любой static server, например Live Server в VS Code.

## Что реализовано

- адаптивная главная страница для desktop, tablet и mobile;
- фирменная подача VERTIKAL: Павлово, Аллея Ильича, 45;
- оптовые и розничные цены в карточках;
- демонстрационная карточка товара с фасовкой, характеристиками и уровнями оптовой цены;
- личный кабинет с заказами, персональной скидкой и бонусным счётом;
- общие стили вынесены в `css/styles.css`;
- демонстрационное поведение поиска и кнопок корзины вынесено в `js/app.js`.
