# Изображения

В текущем концепте используются временные изображения Unsplash, подключённые по URL.

Для production-версии сюда можно положить:

- `hero/` — фотографии для главного баннера;
- `categories/` — изображения категорий;
- `products/` — фотографии товаров;
- `brands/` — логотипы клиентов.

После загрузки локальных файлов URL в HTML заменяются на `images/...`.
